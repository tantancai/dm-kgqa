# ADR-0009：药物归类改为依据指南核对；三张审核表改为"交叉复审 + 人工裁决分歧"

- 状态：已采纳
- 日期：2026-11-03
- 关联：REQ-25；修改 data-model.md（已批准 2026-11-02）第 5、6 节的人工审核方案；细节见 v1.1-design.md 第 5 节、附录 A，v1.1-review-prompts.md

## 背景

data-model.md 原定：药物类别映射中约 150 条降糖药全部人工审，四张表合计人工 8～11 小时，全部由项目作者本人逐条或抽样判断。写 V1.1 设计时发现两个问题：

1. **药物类别是有标准答案的事实。** 2024 版指南原文写明了每类药的归属和药名，例如"磺脲类药物属于胰岛素促泌剂""肠促胰素类降糖药包括 GLP-1RA 和 GIP/GLP-1RA"。作者不是医学专业，逐条审这类表，判断依据其实还是去查指南，人工审核没有增加可信度，只增加工时。
2. **人工审核量集中在第 2～4 周**（v1-design 第 11 节已列为风险），作者同时要兼顾秋招，存在延期风险。

## 可选方案

| 方案 | 优点 | 缺点 |
|---|---|---|
| A. 维持原方案，全部人工 | 口径最简单 | 工时 8～11 小时；药物类别的人工判断反而不如直接对照指南可靠 |
| B. 药物类别依据指南核对；其余三张表全部交给另一家模型审，不再人工 | 作者几乎零工时 | 不满足 REQ-25"人工抽检"；论文中只能写"双模型交叉审核"，说服力下降 |
| C. 药物类别依据指南核对；其余三张表先由另一家模型复审，作者只裁决分歧项，并抽检一致项 | 工时明显下降；通过率仍以人工结论为准，满足 REQ-25 | 依赖复审模型的可靠性，需要兜底规则 |

## 决定

选 C：

1. **药物类别**：类别清单和药物归属以 2024 版指南原文为准（v1.1-design 附录 A）。指南名单内的药直接归类；名单外的按词根规则归类，并附指南证据句；两者都判断不了的由 LLM 预标，全部作为"存疑"交导师确认，确认前不写入图谱。作者不逐条审。
2. **别名、药物关系、饮食三张表**：DeepSeek 预标 → 另一家模型（通义千问、Kimi、GPT 或 Claude 中的一个）按 v1.1-review-prompts.md 复审 → 作者全部裁决"复审与预标不一致"和"复审存疑"的行，并从一致的行中随机抽 10% 确认。
3. **兜底**：某张表一致行的 10% 抽检中错误率超过 5% 时，该表抽检比例提高到 30%，并换一个复审模型重跑一次。
4. **通过率**仍按 data-model 的口径计算，以作者结论为准，门槛 ≥ 95% 不变。

## 理由与代价

- 理由：药物类别交给权威原文，比非专业人员的判断更可靠；交叉复审把人工集中在最可能出错的分歧项上，同样的时间审得更有针对性。预标和复审使用不同厂商的模型，避免同源模型犯相同的错误后互相"确认"。
- 代价：
  - 人工审核量从 8～11 小时降到约 6～9 小时（药物类别减少约 2 小时）；交叉复审再减少多少，要等第一批分歧比例出来才知道。
  - 增加一次复审模型的调用费用，以及 `review merge` 合并命令。
  - 论文中审核方法要如实写成"依据指南原文核对药物类别；LLM 预标 → 异构模型交叉复审 → 人工裁决分歧项并抽检一致项"，不能写成"全部人工审核"。
- 同时纠正：草案曾把 DPP-4 抑制剂归入"肠促胰素类"，对照指南原文后改正（指南中该类只包括 GLP-1RA 和 GIP/GLP-1RA）。
