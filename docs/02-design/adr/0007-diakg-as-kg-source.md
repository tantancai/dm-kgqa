# ADR-0007：以 DiaKG 为图谱主数据，指南饮食知识为补充，不使用 MIMIC

- 状态：已采纳
- 日期：2026-10-30
- 关联：REQ-24、REQ-25、REQ-26、NFR-05

## 背景

原计划沿用大创的图谱数据和模板问答代码，但两者都已经没有了。手头可用的只有 MIMIC 原始数据。图谱需要的是"疾病—症状—药物—饮食"这类中文医学知识，而且要能调用在线 LLM API、做 ToC 演示和试用。

## 可选方案

| 方案 | 优点 | 缺点 |
|---|---|---|
| A. MIMIC（美国 ICU 英文电子病历） | 真实、规模大 | 是病人数据，不是医学知识；数据使用协议禁止发送给第三方 API（PhysioNet 2025-09 规定），不能再分发 |
| B. DiaKG（41 份中文糖尿病指南与专家共识的实体关系标注，天池 dataId=88836） | 题目对口、有论文出处、医生参与标注、每条关系都能对应到原句 | 同义实体未合并；"药物—疾病"关系不区分适用和禁用；几乎没有饮食知识；许可为非商业 |
| C. 全部从指南中用 LLM 抽取 | 覆盖面可控 | 工作量大（多 2～3 周），没有标注质量背书 |
| D. 爬取的开源医疗图谱（如 QASystemOnMedicalKG） | 现成、有饮食数据 | 来源是爬虫，授权不清 |

## 决定

以 B 为主，饮食知识用 C 的方式只补这一块。A 和 D 都不用，D 最多只作为人工参考，不入库。

## 理由与代价

- 盘点结果（2026-10-30）：3,498 句，4,929 个去重实体，4,101 条去重三元组，15 种关系。以用药和并发症为主，高尿酸血症 / 痛风占了 3 份文档。
- 许可是 CC BY-NC，对应要求如下：
  - **署名**：README 和论文中引用 Chang et al. 2021（arXiv:2105.15033），附许可链接，并注明做过清洗和关系细分。
  - **非商业**：不做真实收费，V2b 的会员等级只是模拟的调度优先级。
  - **无附加限制**：仓库中的图谱数据部分单独注明使用 CC BY-NC，不受代码许可的约束。
- 原始数据不进仓库（`kg/raw/` 已忽略）。清洗后的数据是否提交，在 `data-model.md` 中决定。
- 代价：
  - V1 增加约 2 周，用于实体归一化、关系细分、饮食知识抽取和自研模板问答。
  - 药物相互作用不在数据覆盖范围内，PRD 中列为不做。
