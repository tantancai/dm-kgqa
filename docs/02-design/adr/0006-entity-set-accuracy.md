# ADR-0006：准确率按实体集合自动计算，不依赖 LLM 打分

- 状态：已采纳
- 日期：2026-10-29
- 关联：REQ-10、NFR-01

## 背景

四个版本都要在同一个测试集上比较准确率，V2a 还要证明"准确率基本不变"。如果评测方法本身不稳定，版本之间的差异就分不清是系统变了，还是评测在波动。

## 可选方案

| 方案 | 优点 | 缺点 |
|---|---|---|
| A. 让 LLM 当评委，给回答打分 | 能评估自由文本 | 结果有波动，要花调用费用，评委模型本身也会出错 |
| B. 标准答案存成实体集合，和系统查到的实体逐一比对 | 确定、可复现、零成本 | 只适用于答案是实体的题目 |
| C. 以 B 为主，自由文本类题目再用 A 抽检 | 两者的优点兼顾 | 要维护两套评测方法 |

## 决定

以 B 为主。测试集由图谱路径采样生成，标准答案天然就是实体集合。只有回答措辞类的质量检查（是否附了依据、有没有超出查询结果）才用 LLM 抽检，不计入准确率。

## 理由与代价

- 同一份结果跑两次，得分完全一致，版本之间的对比才可信。
- 比对的是系统**实际查到**的实体（来自 `meta` 和 `done.evidence`），而不是从回答文字里解析，避免措辞影响得分。
- 代价：B 衡量不了回答的可读性，这部分放在用户试用的满意度反馈里评估。
